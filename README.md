# Discord Plus

A web-wrapper iOS app for Discord — the full Discord web client
(`https://discord.com/app`, always the latest version) inside a native
shell, with a theme engine, a plugin system, and native settings.

Built for sideloading: the GitHub Actions build produces an **unsigned**
`.ipa`; sign it with your own certificate and install it on your device.

> ⚠️ **Ban risk:** Discord does not allow modified clients. Using a
> modified client — including a web wrapper with injected scripts — can get
> your account banned. **Test with a secondary account first.** This app
> never stores, logs, or transmits your credentials or tokens; you log in
> inside the web view, and only Discord sees your login.

## Features

- **Discord web client, always latest** — loads `discord.com/app` in a
  `WKWebView`. No bundled Discord code, no decryption, no IPA patching.
- **Desktop web client on iPhone** — uses a macOS Safari user agent so
  Discord serves the full desktop web client (the most feature-complete
  web client, with the most stable DOM for plugins). Pinch-zoom works for
  the desktop layout.
- **Theme engine** — 3 built-in themes (Midnight, AMOLED pure black,
  Aurora), custom accent colour (presets + colour picker), font choice
  (system / serif / mono / rounded), and a custom-CSS editor. Choices are
  saved in `UserDefaults` and applied live, without reload.
- **Plugin system** — a loader + `window.DP` plugin API (modeled on the
  Vencord/Kettu pattern, all original code). Bundled plugins plus
  user-added plugins loaded from URLs. Per-plugin enable/disable and
  settings; toggling a plugin reloads the web view.
- **Built-in plugins**
  1. **Copy IDs** — long-press a message, user, server or channel to copy
     its ID.
  2. **Local Timestamps** — full local date/time on message timestamps
     (tooltip, or replace the displayed text).
  3. **Hide Blocked Messages** — hides blocked/ignored message
     placeholders.
  4. **Media Tools** — tap an image to zoom fullscreen, with download;
     videos open in the same lightbox with controls.
  5. **Custom CSS Loader** — applies the CSS you write in Settings.
  6. **Hide Nitro Upsell** — hides Nitro upsell links and buttons.
- **Native settings UI** — SwiftUI, Arabic-first with English (RTL), for
  themes, plugins, custom CSS, and an About screen.
- **Privacy** — no credentials or tokens are stored, logged, or
  transmitted anywhere in the code. Login happens only inside the web
  view. Plugin URLs you add are fetched from your device only.

## Install

1. Download the `DiscordPlus.ipa` artifact from the latest successful
   **Build iOS App** workflow run (Actions tab).
2. Sign the `.ipa` with your own certificate (e.g. with your signing
   tool of choice) and sideload it onto your iPhone.
3. Open Discord Plus, log in to Discord inside the app, and open
   Settings (gear icon) to pick a theme and enable plugins.

## Build locally

Requires Xcode 16+ on macOS:

```bash
xcodebuild -project DiscordPlus.xcodeproj -scheme DiscordPlus \
  -configuration Release -destination 'generic/platform=iOS' \
  CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO \
  clean build
```

The Xcode project is generated by `tools/gen_project.py` from the file
list in that script — edit the file lists there and re-run it instead of
hand-editing `project.pbxproj`.

## Project layout

```
DiscordPlus/
  DiscordPlusApp.swift      App entry point
  App/                      SettingsStore, ThemeEngine, PluginRegistry
  Web/                      WKWebView wrapper, JS bridge, user scripts
  Views/                    SwiftUI: web view, settings, themes, plugins,
                            custom CSS, About
  Resources/JS/             loader.js (window.DP API) + plugins/
  Assets.xcassets/          App icon + accent colour
  Info.plist
.github/workflows/build.yml  macOS runner: build unsigned .ipa -> artifact
tools/gen_project.py          Xcode project generator
```

## Known limits

- **No push notifications** — a web view cannot register for Discord
  push notifications the way the native app does.
- **Voice** — voice/video calls run through the web client inside
  `WKWebView`; behaviour may differ from the native app (audio routing,
  background audio, echo cancellation).
- **Desktop layout on a phone** — the macOS user agent serves the desktop
  web client, so the layout is wide and needs pinch-zoom/scroll. A mobile
  user agent is a possible future option.
- **DOM-dependent plugins** — Copy IDs, timestamps and blocked-message
  hiding read Discord's web DOM, which Discord changes between releases;
  they are best-effort and may need updates after a Discord web update.
- **Downloaded media** goes to the web view's download handling, not to
  the Photos library directly.
